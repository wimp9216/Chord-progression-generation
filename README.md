# Chord Canvas

コード進行を生成・試聴できる、日本語の小さな Web アプリです。

## 開発

Node.js 20 以上を使用してください。外部パッケージ・API キー・データベースは不要です。

```sh
npm start
```

ポート 3000 で起動します。`PORT=3001 npm start` で変更できます。

```sh
npm test
```

## 機能

- 12 キー、メジャー／自然短音階、4・8・16 小節
- 各モードの4種類の定番パターンから4小節ごとに選択
- テンポ指定、Web Audio API による三和音の試聴と停止
- コード進行のコピー（Clipboard API が利用できない場合は文字列表示）

音名はシャープ表記です。試聴はブラウザの音声機能を使用します。

## 構成

`chords.js` は生成ロジック、`app.js` は画面・音声制御、`server.js` は依存パッケージ不要の静的ファイルサーバーです。`melody.js` は音高解析と候補生成、`melody-worker.js` は解析用 Worker です。`tests/` で生成・移調・音高解析・入力検証を確認します。

## GitHub Pages で公開

GitHub の Settings → Pages で「Deploy from a branch」を選び、`main` ブランチの `/ (root)` を指定して保存します。ビルドや Node.js サーバーは不要です。公開後の URL は `https://wimp9216.github.io/Chord-progression-generation/` です。

## メロディから候補を生成

1. キー・モード・テンポをメロディに合わせます（自動推定は行いません）。
2. 「録音を開始」でマイクを許可し、伴奏なしの歌声・鼻歌・単音楽器を録音します。または音声ファイルを読み込みます。
3. 「メロディから候補を生成」で3つの候補を表示します。
4. 「この候補を選択」で、通常の試聴・停止・コピー機能を使えます。

音声はブラウザ内でデコードし、Web Worker で単音の音高を検出します。指定キー内の三和音について、小節ごとのメロディ音との一致とコード間の移行を評価し、3つの異なる進行を提案します。サーバーへの音声送信はありません。

録音はHTTPSまたはlocalhostとマイクの許可が必要です。録音は60秒で停止し、解析対象も先頭60秒までです。ファイルは60秒以内・20MB以下で、ブラウザがデコードできる形式（WAV、MP3など）に限ります。録音の先頭を第1小節の開始として、指定テンポから小節を区切ります。解析では75〜1000Hzの単音を対象とするため、伴奏付き音源・複数の声・ノイズ・低すぎる音などでは精度が下がります。候補は編曲の出発点として試聴して選んでください。

`npm test` は生成ロジックに加え、合成音による音高検出、無音、音の変化、タイミング、候補の一致・多様性を確認します。
