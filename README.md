# Chord Canvas

コード進行を生成・試聴できる、日本語の小さな Web アプリです。

## 開発

Node.js 20 以上を使用してください。外部パッケージ・API キー・データベースは不要です。

```sh
npm start
```

ポート 3000 で起動します。`PORT=3001 npm start` で変更できます。

```sh
npm test
```

## 機能

- 12 キー、メジャー／自然短音階、4・8・16 小節
- 各モードの4種類の定番パターンから4小節ごとに選択
- テンポ指定、Web Audio API による三和音の試聴と停止
- コード進行のコピー（Clipboard API が利用できない場合は文字列表示）

音名はシャープ表記です。試聴はブラウザの音声機能を使用します。

## 構成

`chords.js` は生成ロジック、`app.js` は画面・音声制御、`server.js` は依存パッケージ不要の静的ファイルサーバーです。`melody.js` は音高解析と候補生成、`melody-worker.js` は解析用 Worker です。`tests/` で生成・移調・音高解析・入力検証を確認します。

## GitHub Pages で公開

GitHub の Settings → Pages で「Deploy from a branch」を選び、`main` ブランチの `/ (root)` を指定して保存します。ビルドや Node.js サーバーは不要です。公開後の URL は `https://wimp9216.github.io/Chord-progression-generation/` です。

## メロディから候補を生成

1. 伴奏なしのメロディを用意します。上部のキー・モード・テンポは音声解析に使用しません。
2. 「録音を開始」でマイクを許可し、伴奏なしの歌声・鼻歌・単音楽器を録音します。または音声ファイルを読み込みます。
3. 「メロディから候補を生成」で3つの候補を表示します。
4. 「この候補を選択」で、通常の試聴・停止・コピー機能を使えます。

音声はブラウザ内でデコードし、Web Worker で単音の音高を検出します。検出音の長さ・信頼度を重みとして24種類のキー／モードを評価し、推定音階の7つのダイアトニック三和音を算出します。音の立ち上がりの間隔からBPMを推定し、区間ごとのメロディ音との一致とコード間の移行を評価して、3つの異なる進行を提案します。推定キー・ダイアトニックコード・BPMを画面に表示します。サーバーへの音声送信はありません。

録音はHTTPSまたはlocalhostとマイクの許可が必要です。録音は60秒で停止し、解析対象も先頭60秒までです。ファイルは60秒以内・20MB以下で、ブラウザがデコードできる形式（WAV、MP3など）に限ります。推定テンポがある場合は最初の検出アタックを区切りの起点とし、4拍を1小節として扱います。テンポを特定できない場合は音声を4等分し、試聴用テンポのみ100 BPMにします。拍子・小節頭・弱起は自動認識しません。解析では75〜1000Hzの単音を対象とするため、伴奏付き音源・複数の声・ノイズ・低すぎる音などでは精度が下がります。候補は編曲の出発点として試聴して選んでください。

`npm test` は生成ロジックに加え、合成音による音高検出、無音、音の変化、タイミング、候補の一致・多様性を確認します。

キー推定は短いメロディや相対調で曖昧になるため、その場合は別のキーの可能性も表示します。BPMは音符の長さによって倍・半分になることがあります。マイナーのダイアトニックコードは自然短音階を使用します。候補を選ぶと、試聴用の上部設定に推定結果が反映されます。

## ピアノロールでメロディを編集

「メロディから候補を生成」で音声を解析すると、検出した音符をピアノロールに表示します。縦軸は音程、横軸は秒です。スクロールして全体を確認できます。

- 音符のドラッグで音程と開始位置を変更します。開始位置は0.05秒単位です。
- 音符の右端をドラッグすると長さを変更できます。
- 音符を選択し、MIDI番号・開始秒・長さ秒を入力して「選択音符を更新」でも修正できます。MIDI番号60はC4です。
- 空白をダブルクリック、または「音符を追加」で追加します。選択した音符は削除ボタンやDeleteキーで削除できます。
- 音符にフォーカスした状態で上下キーは半音、左右キーは0.05秒移動します。
- 「元に戻す」「やり直す」は直近50操作を保持します。「解析直後に戻す」は初期の検出音符に戻します。
- 編集すると古いコード候補を消します。「メロディから候補を生成」を再度押すと、編集した音符からキー・テンポとコード候補を再計算します。
- 「メロディを試聴」で編集結果を合成音で確認します。上の音声プレーヤーは元の音声を再生します。
- 「MIDIを書き出す」で標準MIDIファイル（Format 0、480 PPQ、テンポ情報付き）を保存し、DAWに取り込めます。開始位置と長さは秒のタイミングを保持して書き出します。

編集データは開いているページ内で保持します。ページを閉じる／再読み込みする前にMIDIを書き出してください。別の音声を読み込むと編集内容を初期化します。音声からの変換は単音メロディ向けで、短い音や繰り返し音の区切りを誤検出することがあります。音符編集はMIDI番号24〜108、先頭60秒の範囲です。MIDIファイルの読み込みには未対応です。

## メロディとコードを同期して確認

音声解析後はメロディのピアノロールの直下に、候補1のコードを三和音のピアノロールとして表示します。別の候補を選ぶとコード表示も切り替わります。上下の横軸は同じ秒表示・縮尺で、横スクロールが同期します。

- 「メロディのみ再生」は編集した音符を合成音で再生します。
- 「メロディ＋コードを再生」は両トラックを共通の音声クロックで同時再生します。
- 赤い再生位置の線と発音中の音符の色で、現在位置を確認できます。「停止」で両トラックを止めます。
- 自動推定できた場合は候補生成時のBPMと開始位置に合わせ、最後のコードは音声の長さに合わせて切ります。テンポが不明な場合は候補生成と同じ4等分の時間区間を使用します。
- 上部から別のコード進行を生成した場合もコードのピアノロールを更新します。この場合は上部のテンポを使い、音声の先頭から配置します。
- メロディの編集後はコード表示を消します。候補を再生成してから同時再生してください。

コードのピアノロールは確認用です。直接編集やコードを含めたMIDI書き出しには未対応です。メロディのMIDI書き出しは引き続き利用できます。
