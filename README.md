# Chord Canvas — Melody Studio

録音・音声ファイルからメロディを解析し、DAW風のピアノロールで編集してコード進行を提案する日本語Webアプリです。音声はブラウザ内で処理します。

## 開発

Node.js 20以上。外部パッケージ、APIキー、データベースは不要です。

```sh
npm start
npm test
```

開発サーバーはポート3000で起動します。`PORT=3001 npm start`で変更できます。
GitHub PagesはSettings → Pagesで「Deploy from a branch」、`main`と`/ (root)`を指定します。ビルドは不要です。

## 使い方

1. 伴奏なしの歌声・鼻歌・単音楽器を録音するか、音声ファイルを選択します。
2. 「メロディから候補を生成」で音高・キー・モード・テンポを推定します。手動のキー・モード・小節数・テンポ設定はありません。
3. メロディと候補1のコードを上下のピアノロールに表示します。候補カードを選ぶとコードトラックが直接切り替わり、選択状態を表示します。
4. 「メロディのみ再生」または「メロディ＋コードを再生」で確認します。再生位置の線と横スクロールは同期します。「停止」で再生を止めます。
5. メロディを編集したら、候補を再生成してください。編集時は古い候補とコード表示を消します。

## ピアノロール編集

横軸は秒、縦軸は音程です。音符のドラッグで音程・位置を変更し、右端のドラッグで長さを変更できます。空白をダブルクリック、または「音符を追加」で追加します。

音符を選んでMIDI番号・開始秒・長さ秒を入力し、「選択音符を更新」でも修正できます。MIDI番号60はC4です。Delete/Backspaceで削除、上下キーで半音、左右キーで0.05秒移動できます。「元に戻す」「やり直す」は直近50操作に対応し、「解析直後に戻す」で検出直後の状態に戻せます。

編集状態は開いているページ内で保持します。別の音声の選択やページの再読み込みで消えるため、必要なら「MIDIを書き出す」で保存してください。Format 0、480 PPQ、テンポ情報付きの標準MIDIとしてメロディを保存できます。コードトラックの直接編集・コードを含むMIDI書き出し・MIDI読み込みには未対応です。上の音声プレーヤーは元の音声を再生し、ピアノロールの再生は編集した音符の合成音です。

## 解析とタイミング

音の長さと信頼度を重みとして24種類のキー／モードを評価し、推定音階の7つのダイアトニック三和音から3つの候補を生成します。マイナーは自然短音階です。短いメロディや相対調ではキーが曖昧になるため、別の可能性も表示します。

音の立ち上がりからBPMを推定します。BPMは倍・半分になることがあります。推定時は最初のアタックを起点として4拍ごとにコードを配置し、最後は音声の長さに合わせます。テンポが不明な場合は音声を4等分し、その時間区間でコードを配置・同期再生します。100 BPMはこの場合のMIDI書き出し用テンポにのみ使用します。拍子・小節頭・弱起は自動認識しません。

録音にはHTTPSまたはlocalhostとマイク許可が必要です。録音は60秒で停止し、解析対象も先頭60秒までです。ファイルは60秒以内・20MB以下で、ブラウザがデコードできる形式（WAV、MP3など）に限ります。音高解析は75〜1000Hzの単音向けで、伴奏・複数の声・ノイズで精度が下がります。候補は試聴して選んでください。

## 構成・検証

`app.js`が入力と候補選択、`melody.js`が音高・調性・テンポ・コード候補、`melody-worker.js`が音声解析、`piano-roll.js`が編集と同期再生、`midi.js`が音符変換とMIDI書き出し、`server.js`が開発用静的サーバーです。`npm test`で音高・調性・候補生成・編集連携・MIDIイベント・同期タイミングを検証します。

## 歌声のピッチの揺れをまとめる

音声解析では半音に丸める前のピッチを保持し、時間方向の中央値で短い飛びを抑えます。中心音から75セント未満の揺れは同じ音として扱い、新しい音程が約120ミリ秒以上持続したときに切り替えます。切り替え位置は変化の開始まで戻すため、確認待ちによる音符の開始遅延を避けます。休符と検出した発音開始では判定を区切り、歌い直しを残します。

この安定化をピアノロールとコード候補生成の両方に適用します。手で編集した音符には再適用しません。短い装飾音や小さな音程移動はまとまる場合があるので、必要に応じてピアノロールで修正してください。意図した音程を確実に認識するものではありません。
